# webui

WebUI chat satu berkas (`index.html`) dengan CSS dan JavaScript inline, tanpa CDN, Node, atau build
step. UI disematkan ke binary engine.

Status: **implementasi lengkap**; parser `<think>`, SSE, parameter sampling, stop string, MTP/PLD,
dan telemetry diuji dengan QuickJS. Halaman belum dibuka di browser sungguhan.

Baca dulu `.agents/skills/webui-and-parity-bench/SKILL.md`.

# qwen38-engine

Dedicated workspace for a hardware-locked inference engine for Qwen3.8-27B on a GTX 1070 Ti (sm_61),
Ryzen 5 2400G (znver1), and 16 GB DDR4.

- Start with `AGENTS.md` (also `CLAUDE.md`).
- Check the environment: `scripts/setup.sh`. Report: `docs/setup-report.md`.
- Domain skills: `.agents/skills/`.

Status: stage 0 (scaffold). No engine source code yet.

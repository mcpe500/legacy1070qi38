## Header GGUF dibandingkan dengan kartu resmi

`gguf inspect` dan `gguf-py`: `architecture=qwen35`, `embedding_length=5120`, `head_count_kv=4`, `key_length=256`, `full_attention_interval=4`, `kv_layers_estimate=16` cocok.

`[CONFLICT]` kecil: `block_count=65`, bukan 64. Layer ke-65 (`blk.64.*`) adalah layer MTP: `qwen35.nextn_predict_layers=1` dan tensor `blk.64.nextn.{eh_proj,enorm,hnorm,shared_head_norm}` ada. Jadi 64 layer utama + 1 layer MTP. `output.weight` terpisah dari `token_embd.weight`.

Build utama **tidak bisa** memuat `Qwen3.8-9B-Q4_K_M.gguf` milik pengguna (`wrong number of tensors; expected 442, got 427`). File 9B lain (`unsloth-Qwen3.5-9B-IQ4_XS`) jalan: 35.62 tok/s tg32, 659 tok/s pp128 pada `-ngl 99`.
